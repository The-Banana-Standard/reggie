## gotcha · 2026-09-17 · Claude via jacobpress · medium
The line number gutter is sticky and opaque so code can scroll sideways under it, which means a tinted diff row cannot lay a translucent colour over it: the added and deleted tints are written as the solid colours that twelve percent of the ok and bad tokens make over the background, once for the row and once for its gutter. Change a token and these four literals need recomputing. Below 1100 pixels the head chips are hidden in plain mode and kept in diff mode, on a row of their own, because there they say whose change is on screen.
