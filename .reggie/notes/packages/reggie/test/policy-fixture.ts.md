## how · 2026-09-18 · Claude via jacobpress · high
makePolicyFixture builds a throwaway repo in the state the policy judges: onboarded, a plan committed on the base, a worktree claim, a code commit, saved evidence, a check recorded for every criterion through recordCheck, and a filled packet, all committed. Options stop it earlier, leave the plan off the base with an in-place claim, replace the policy block, add base files, or write the Discovered issues. It refuses to build anywhere but under the OS temp directory, because this code runs git commit and a test of the code that approves and merges work must not be able to reach a real checkout. The browser checks serve the same repos.
