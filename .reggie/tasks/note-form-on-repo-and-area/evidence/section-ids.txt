Criteria 2, 3, 4, 9, 10, 11, 12, 13, 14, 15 — measured from a throwaway probe over the BUILT dist
of this worktree, not reasoned about. The probe builds six purpose-built git repos, renders
repoStory / areaStory / fileStory over each in the default lens and under lens=knowledge, and
prints the section ids, the add-note section, its empty text, its terminal hint, and which
sections carry a note form.

The probe script is kept out of the repo (vitest.config.ts includes only src/** and test/**);
it lived in the session scratchpad and was run as:
  $ DIST="file://$PWD/dist" node <scratchpad>/probe.mjs
