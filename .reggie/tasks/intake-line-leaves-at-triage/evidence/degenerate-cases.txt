## 3. --force after the line is already gone.
Before: --force replaced Problem with the placeholder AND collapsed the title
to the slug, which under the new rule would also demote the card to ungroomed.
$ reggie tasks   (the filled-in brief, before --force)
  forced [P1 · small] · probe
    Cap login retries on web (brief on disk; no plan yet)
$ reggie triage forced --force
Rewrote .reggie/tasks/forced/brief.md
$ head -3 .reggie/tasks/forced/brief.md ; sed -n '/## Problem/,/^$/p' .reggie/tasks/forced/brief.md
slug: forced
title: Cap login retries on web
## Problem
Web clients retry login forever when the server is down, so nobody can tell an outage from a broken page.

$ reggie triage forced --force --title "A title the owner typed"
Rewrote .reggie/tasks/forced/brief.md
title: A title the owner typed
## Problem
Web clients retry login forever when the server is down, so nobody can tell an outage from a broken page.


NOTE: --force rewrites the other sections back to the scaffold, which is what
--force has always meant ("discarding what it says"), so the card is ungroomed
afterwards. What is preserved is the title and the Problem — the captured words.
