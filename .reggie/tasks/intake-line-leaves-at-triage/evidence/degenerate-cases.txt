$ sed -n '/## Problem/,/## Why now/p' .reggie/tasks/collide/brief.md

detail under the first

detail under the second

## Why now
$ grep -c collide .reggie/intake.md   (lines left carrying the slug)

## 3. --force after the line is already gone.
Before: --force replaced Problem with the placeholder AND collapsed the title
to the slug, which under the new rule would also demote the card to ungroomed.
$ reggie tasks   (the filled-in brief, before --force)
  forced [P1 · small] · probe
    Cap login retries on web (brief on disk; no plan yet)
$ reggie triage forced --force
Rewrote .reggie/tasks/forced/brief.md
$ the title and Problem that survived:
title: Cap login retries on web
## Problem
Web clients retry login forever when the server is down, so nobody can tell an outage from a broken page. (probe, cli, 2026-09-15)

$ reggie triage forced --force --title "A title the owner typed"
Rewrote .reggie/tasks/forced/brief.md
title: A title the owner typed

The capture stamp travels too, so who captured it and when survive the line's deletion.
--force still rewrites the other sections back to the scaffold, which is what it has
always meant ("discarding what it says"), so the card is ungroomed afterwards.

## 6. docs.ts generating the old rule into every onboarded repo.
Before: 'Task state is read from git: intake line = ungroomed, brief.md = groomed, ...'
$ grep 'Task state is read from git' $T/CLAUDE.md $T/AGENTS.md   (a repo onboarded by this branch)
- Mode: **solo**. Task state is read from git: an intake line, or a `brief.md` still holding triage's scaffold, = ungroomed; a `brief.md` somebody has written into = groomed; a plan that passes the contract = planned; `task/<slug>` branch = in process; open PR = awaiting decision; merged = done.
- Mode: **solo**. Task state is read from git: an intake line, or a `brief.md` still holding triage's scaffold, = ungroomed; a `brief.md` somebody has written into = groomed; a plan that passes the contract = planned; `task/<slug>` branch = in process; open PR = awaiting decision; merged = done.
$ the line after it:
- Shape a raw item first: `reggie triage <slug>` scaffolds the brief and removes the intake line, then fill every section in and check it with `reggie brief lint <slug>` — the card stays ungroomed until you do. Plan in plan mode against the contract, then `reggie claim <slug>` to start work on a `task/<slug>` branch. Finish with `reggie packet <slug>` and a PR whose body is the packet.
