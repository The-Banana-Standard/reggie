Every row is OK, and it is not a coincidence that holds on this repo: graph.ts increments
testedSource only for a node whose role is "source", and source counts exactly those nodes, so
testedSource <= source by construction at every level of the fold. The BEFORE run in
rendered-before-after.txt shows what the old clause printed against the same numbers — 66 against
38 source files, 86 against 52 — which was never a count of tested anything.

The same bound is asserted per area in the new test ("prints one wording at every site, and never
more tested than source"), so a future change that breaks it fails the suite rather than waiting
for someone to read a page.
