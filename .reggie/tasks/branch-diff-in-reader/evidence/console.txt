## Before: the first working build, which did what the plan described

The plan has the file page ask /api/story, /api/impact and /api/explain and treat their 404s as ordinary in diff mode. It did, and the page looked
right, but Chrome logs a failed fetch itself, whatever the page does with it. The same unmapped page then read:

That is why /api/filediff now answers `mapped`, and why a file page in diff mode asks for the change first and skips the three requests when it is false.
