The empty-state cases below the diff are new and cover every reason the canvas can be empty:
  - nothing readable at all  -> the card names the skipped total and its languages
  - three languages, all named -> 'in X, Y and Z', no 'mostly' asserting a remainder
  - four languages, three named -> ', mostly X, Y and Z'
  - code read but nothing drawable (every area candidate folded) -> the OLD text stands,
    because the language is not the reason and claiming it is would be a worse lie
  - dir level -> unchanged, and captured: it carries the same falsehood for a folder
  - a hand-built model with no counts block -> footerFor returns a line rather than throwing
  - exactly one -> '1 import points at no file', the verb agreeing with the count
The footer is "" in every empty case (criterion 14).
