packages/reggie/docs/ui-api-contract.md:100:`unresolved` counts distinct (importing file, **relative** specifier) pairs: one bad path written twice in one file is one and the same bad path imported from two files is two. Only specifiers starting with `.` are counted. An unresolvable `@/` or `~/` alias, and any bare package specifier, is dropped with no edge and no count, so a zero here means "no path-style import failed" and not "every import was followed".
