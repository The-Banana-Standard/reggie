$ npx tsx src/cli.ts journal derive --help
Usage: reggie journal derive [options] <slug>

Write a journal entry from a task's commits and the closing words of its
launched Claude sessions; appends what is new, prints all of it, and never
commits

Options:
  --session <uuid>  also read this Claude session's transcript; it must have
                    worked inside this repository
  --dry-run         print the entry and the summary, write nothing
  --rewrite         off by default: send the entry's text, and nothing else, to
                    the session's own tool (claude -p) for one rewrite per
                    entry; any failure keeps the template
  -h, --help        display help for command
exit: 0
