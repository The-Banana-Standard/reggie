# reggie

Curated notes for anyone, human or agent, working in this repo. Edit freely outside the generated block.

## Conventions
- Develop the `repo-manager` branch in a git worktree, never by checking it out in the main clone: `~/.claude/*` symlinks point into this repo's `resources/`.
- Reggie owns state, contracts, policy, and glue. Borrow procedures (plan mode, `/code-review`, `/security-review`, `/simplify`) by name; never copy them into this repo.
- Nothing durable is gitignored. New state is a file under `.reggie/` or something git already records.
- Every feature must work for a team: attributed writes, no shared-file conflicts, no silent takeovers.

## Decisions
- 2026-09-06: Reggie becomes a repo manager (CLI + MCP under `packages/reggie/`) and the Tauri desktop app is decommissioned on this branch. Rationale and open forks: `docs/repo-manager-vision.md`.
- Task state is derived from git (intake line, plan on main, `task/<slug>` branch, open PR, merged PR), not stored.

## Gotchas
- `npm install` in `packages/reggie` needs `--legacy-peer-deps`; npm 10.9 crashes resolving vitest 4 peers otherwise.
- `reggie docs check` counts untracked files as part of the repo; run it on a clean tree.
